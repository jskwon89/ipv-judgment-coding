## 수단·요구 세부 판정

1. 법원이 인정한 사실(범죄사실, 양형이유에서 인정한 내용)만 근거로 한다. 공소사실에만 있고 법원이 인정하지 않았거나, 어느 범행에 속하는지 불분명한 내용은 9로 코딩한다.

2. 코드는 1(해당), 0(판결문에 기재 없음), 9(기재는 있으나 판단 불가)로 한다.

3. 한 범행에 수단과 요구가 여러 개 있을 수 있다. 해당하는 것을 모두 1로 코딩한다.

5. 판결문에 쓰이지 않은 의도나 목적을 추측하여 코딩하지 않는다. 요구는 판결문에 요구 내용이 드러나 있을 때만 1이다.

- 횟수미상행위포함_6차: 미상 행위가 있으면 1, 범위 내 전부 수량 확인 시 0, 적용 범위 자체를 판단할 수 없으면 공란.
- 수량 범위와 근사 표현은 원형을 보존한다. 2~3회는 하한 2·상한 3이며 단일 정확값으로 치환하지 않는다. 약 20회는 정확한 20회로 합산하지 않는다.
- 행위횟수_6차_최소확인범주: 코드 1=최소 1회 확인, 2=최소 2회 확인, 3=최소 3회 확인, 4=최소 4회 확인, 5=최소 5회 이상 확인. 확인 가능한 가장 높은 범주 하나만 부여한다. 실제 횟수가 그 코드와 같다는 뜻은 아니다. 최소 횟수도 판단 불가하면 공란.
- 수회·여러 차례처럼 반복을 명시한 표현은 최소확인범주 산출에서 최소 2회로 인정한다. 이 2는 명시행위횟수_6차의 정확한 수량 합계에 넣지 않는다.
- 최소 횟수 산출에서도 같은 행위의 본문·별지·죄명 중복을 제거한다. 중복 범위가 불명확한 반복 표현을 독립 행위군으로 추정하여 가산하지 않는다.
- 예: 명시 23회 + 수회 → 명시 합계 23, 미상 포함 1, 최소확인범주 5. 2~3회만 확인 → 정확 합계 공란, 범위 2~3, 최소확인범주 2. 정확히 4회만 확인 → 명시 합계 4, 미상 포함 0, 최소확인범주 4.
- 첫 6차에 포함되는 사건 범위 자체가 불명확하면 관계 전체의 해당 변수값을 확정하지 않는다. 범위가 특정된 부분 소계는 그 범위를 명시하여 별도 보존한다.

후속 논의: 구체적인 과거 사건과 불특정 과거력의 차수 편입, 유죄·기각·무죄 지위에 따른 집계 범위, 독립 행위의 분할 경계. 아직 미승인인 사항을 승인된 것으로 적용하지 않는다.

## 2026-11-12 사용자 승인 2: 과거 사건의 차수 편입

- 구체적인 과거 사건은 차수에 포함한다. 정확한 날짜가 없어도 서술 순서·시기·내용으로 독립된 사건이 식별되면 편입한다.
- 평소 자주 폭행했다 등 개별 사건을 특정할 수 없는 불특정 과거력은 별도 기록한다. 임의의 사건이나 차수를 생성하지 않는다.
- 첫 6차는 자료에서 개별 사건으로 식별된 순서상 첫 6차다. 관계 전체에서 실제 발생한 최초 6개 사건을 완전히 관측했다는 의미가 아니다.
- 선행 사건 편입으로 기존 차수가 달라지면 첫 6차 범위를 재산출한다. 횟수가 미상인 선행 사건 때문에 다른 확정 범위의 명시 수량 소계를 폐기하지 않고 미상 포함 여부를 함께 보존한다.
- 대체 날짜와 실제 날짜, 서술 순서의 근거를 구분한다. 같은 대체 날짜라는 이유만으로 별개 사건을 자동 병합하지 않는다.
- 공소기각·무죄·공소 주장 등의 인정 지위에 따른 분석 포함 여부는 다음 논의 사항이며, 이번 승인만으로 확정하지 않는다.

상태: 규칙 저장 완료. 전체 자료의 차수 재배치·집계 재산출은 아직 적용하지 않음.

## 2026-11-12 사용자 승인 3: 행위 인정·IPV 해당 여부에 따른 주 분석

- 행위 발생의 인정 상태, 해당 행위의 재판 결과, 연구상 IPV 해당 여부를 서로 분리하여 기록한다.
- 행위 발생 인정 상태: 법원 인정 / 공소·진술에만 기재 / 법원이 발생을 부정 / 판단 불명.
- 해당 행위 재판 결과: 유죄 / 무죄 / 공소기각 / 별도 판단 없음. 판결문 전체 주문을 개별 행위에 일괄 전파하지 않는다.
- 연구상 IPV 해당 여부: 해당 / 비해당 / 판단 보류.
- 주 분석에는 법원이 발생을 인정했고 연구상 IPV에 해당하는 행위를 포함한다. 유죄 여부만으로 포함·제외를 결정하지 않는다.
- 공소·진술에만 등장하는 행위는 기재 횟수와 지위를 보존하되 주 분석과 분리한다. 무죄·공소기각이라는 이유만으로 행위 없음 0으로 바꾸거나, 반대로 공소사실을 법원 인정행위로 간주하지 않는다.
- 법원이 발생을 인정한 행동이어도 연구상 IPV 비해당이면 IPV 행위 합계에서 제외한다. 판정 불명은 확정 포함하지 않는다.
- 분석 포함에 따른 첫 6차 재선정 방법 및 개별 행위의 분할 경계는 아직 이번 승인으로 확정하지 않는다.

상태: 승인 규칙 저장. 전수 값 재산출·공개 저장소 갱신은 아직 수행하지 않음.

## 2026-11-12 사용자 승인 4: 독립 행동과 중복 제거

- 한 사건 안에서 원문에 구별되는 독립된 행동은 각각 계수한다. 사건 차수와 그 안의 행위 횟수를 구별한다.
- 다른 행동이 순차적으로 명시되면 각각 계수하고, 같은 행동의 명시적 반복은 명시 횟수를 적용한다.
- 동일 행동의 설명·재서술·복수 죄명·결과는 중복 계수하지 않는다. 예: 투척 한 번으로 손괴와 상해가 발생해도 투척은 1회.
- 물건·신체 부위·피해 결과 개수를 행동 횟수로 자동 변환하지 않는다. 원문에서 하나의 절취로 식별되는 행위를 미세한 운반 동작 수 미상만으로 보류하지 않는다.
- 동작과 동시의 발언이 같은 위협 행동을 설명하면 합친다. 별도로 이어진 독립 협박·강요·연락은 별도 행동으로 계수한다.
- 원문이 두 표현을 같은 동작의 설명으로 쓰는지 독립 동작으로 쓰는지 불명확한 경우 해당 경계만 보류하고 명시 수량은 보존한다.
- 예시 적용 원칙: ADD289의 칼 2회와 의자 투척 2회는 4회. ADD019의 문짝 9회 중 한 번이 상해를 발생시켜도 그 부분은 9회. ADD217의 침입·절취·별도 위협 메시지는 3개 행동으로 분리하며 반려견 2마리를 절취 2회로 바꾸지 않는다.

상태: 승인 규칙 저장. 전수 수치 재산출은 아직 수행하지 않음. 디지털 발송 묶음의 세부 기준은 다음 논의 사항.

## 2026-11-12 사용자 승인 5: 디지털 발송 횟수

- 사진·문장·파일·수신인 수가 아니라 실제 발송 횟수를 계수한다.
- 발송 횟수가 명시되거나 개별 발송이 식별되면 그 횟수를 적용한다. 한 번에 여러 파일·문구를 보냈다고 확인되면 발송 1회로 기록하고 내용물 수는 별도 보존한다.
- 전송 사실은 있으나 몇 번에 나누어 보냈는지 구분되지 않으면 정확 발송 횟수는 공란, 최소 1회 확인으로 기록한다. 임의의 1을 정확한 명시 합계에 넣지 않는다.
- 여러 차례 전송 등 반복이 명시되면 최소 2회로 인정하되 정확한 명시 횟수 합계에는 2를 넣지 않는다.
- 서로 다른 발송임이 확인되면 같은 내용·같은 표시 시각이어도 별개로 계수한다. 본문·별지·죄명에서 같은 발송을 반복 서술하면 중복 제외한다.
- 단체방 수신인 수로 발송 수를 늘리지 않는다. 초대·게시가 독립 행동이면 구별하되, 초대 인원 수를 초대 실행 횟수로 추정하지 않는다.

상태: 승인 규칙 저장. 전수 재산출 전. 다음 논의: 같은 날짜의 독립 사건과 연속 사건의 차수 구분.

## 2026-11-12 사용자 승인 6: 독립 사건별 차수

- 같은 날짜여도 독립된 사건이면 별도 차수를 부여한다. 하루를 자동으로 한 차수로 묶지 않는다.
- 한 사건에서 연속된 여러 행동은 해당 차수 안의 행위 횟수로 계수한다.
- 종료 후 재방문·재접촉하여 새로운 사건이 시작되면 별도 차수. 장소 이동만으로 차수를 분리하지 않는다.
- 정확한 날짜가 불명확해도 독립 사건과 순서를 식별할 수 있으면 별도 차수를 부여하고 날짜 불확실성을 표시한다. 같은 대체 날짜라고 자동 병합하지 않는다.
- 별개의 메시지 발송을 매번 별도 차수로 만들지 않는다. 한 차례 연속 연락에서 발송 10회는 사건 1차 안의 행위 10회로 구별한다.
- 종료·재개 경계가 불명확하면 임의의 시간 간격 기준을 만들지 않고 해당 경계만 표시한다.

상태: 규칙 저장, 전수 차수 재배치 및 합계 재산출 전.

## 2026-11-13 사용자 승인 7: 전체 기록 순서와 주 분석 차수 분리

- 전체 기록 순서는 제외·보류 사건도 포함하여 보존한다.
- 주 분석에는 법원이 발생을 인정했고 연구상 IPV에 해당하는 독립 사건만 포함하고, 그 사건들에 별도로 시간순 차수를 매긴다.
- 6차 이내 행위 합계는 주 분석 차수 1~6에서 산출한다. 공소·진술만의 행위나 IPV 비해당 사건이 전체 기록에 끼어 있어도 주 분석 차수를 차지하지 않는다.
- 적격 사건이 6개 미만이면 존재하는 사건까지만 합산하고 실제 포함 사건 수를 함께 기록한다.
- 이는 자료에서 확인되어 주 분석에 포함된 첫 6개 사건이며, 관계에서 실제 발생한 최초 6개를 완전히 관측했다는 뜻은 아니다.
- 사건 고유 식별자와 전체 기록 순서, 주 분석 차수를 구별하여 제외·재배열의 근거를 추적할 수 있게 한다.

상태: 승인 규칙 저장. 전수 사건 재배열·집계 재산출 및 Git 갱신은 아직 수행하지 않음.

## 2026-11-13 사용자 승인 8: 제3자 경유 가해의 관계 귀속

- 제3자를 거쳐도 파트너를 겨냥한 가해로 확인되면 해당 IPV 관계에 포함한다. 법원 인정 및 연구상 IPV 해당이라는 주 분석 요건을 함께 적용한다.
- 제3자만 향한 별개의 행위는 파트너 관계의 행위 수와 분리하여 별도 피해 행위로 기록한다.
- 직접 수신·접촉 대상과 IPV 피해 귀속 관계를 구별한다. 가족·지인에게 연락했다는 사실만으로 파트너 대상 가해로 추정하지 않는다.
- 가해 경로, 직접 수신·접촉 대상, IPV 피해 귀속 관계, 귀속 근거를 보존한다. 대상이 불명확하면 해당 귀속 셀만 보류한다.
- 하나의 행동이 파트너와 제3자 모두에게 피해를 준 경우 피해 대상별 연결을 보존하되 공통 행위ID로 동일 행동을 연결하여 전체 합산 시 중복을 제거한다.
- 제3자에게 전달을 시도한 사실과 실제 피해자에게 전달된 사실은 구별하여 기록한다.

상태: 승인 규칙 저장. 전수 관계 귀속·횟수 재산출 전. 다음 논의: 여러 판결문 간 동일 관계·사건 연결 및 중복 처리.

## 2026-11-13 사용자 승인 9: 판결문 간 동일 관계·사건 연결

- 판결문과 문서ID는 모두 보존한다. 동일 관계·사건 연결 때문에 원심·항소심 문서를 삭제하지 않는다.
- 원심 사건번호, 범행 일시·내용 등 근거로 동일 관계·사건임을 확인하여 통합 관계ID와 통합 사건ID·행위ID로 연결한다. 익명 기호 일치만으로 병합하지 않는다.
- 동일 범행은 한 번만 계수하며, 실제 새로운 후속 범행은 별도 사건으로 추가한다.
- 항소심이 원심 사실을 인용하면 원심 상세 사실을 활용하고 두 출처를 연결한다. 확보된 후속심이 특정 사실·횟수·판단을 명시적으로 변경하면 해당 판단을 반영하되 이전 값과 변경 이력을 보존한다.
- 형량·합의 등 후속 사정만 바뀌면 해당 정보만 갱신하고 범행 횟수를 중복 가산하지 않는다. 이후의 관계 변화를 범행 시점에 소급하지 않는다.
- 동일성 불명확은 연결 후보로 보존하고 자동 병합하지 않는다. 확보된 가장 나중 판결과 법적 확정 여부를 구별한다.
- 연결된 동일 관계의 중복 없는 사건들을 순서대로 정리하여 주 분석 첫 6차를 산출한다.

상태: 승인 규칙 저장. 전수 관계·사건 연결 및 차수·집계 재산출 전. 다음 논의: 범위·근사수와 날짜 불확실성 처리.

## 2026-11-13 사용자 승인 10: 수량·날짜 정밀도와 영향 범위
