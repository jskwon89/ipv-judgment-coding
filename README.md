# 친밀한 파트너 폭력 판결문 코딩

2026-11-04 작업본. 판결문 621건의 사건번호, 구조화한 코딩값, 코딩 규칙과 출처별 변수 대응표를 공개한다. 전체 변수의 원문 재판독은 진행 중이다.

[통합 규칙](rules/통합코딩규칙.md) · [통합 코드북](codebook/00_통합코드북.csv) · [공개 열 및 생략 범위](codebook/공개열_대응.csv)

판결문은 문서ID와 법원·대표사건번호로 식별한다. 직접 피해관계 내 날짜 차수 하나가 사건 한 행이다. 사건차수 전체 2,906행에는 주변인 행이 포함되며, 수단·요구 예비분석은 별도로 선정한 726행이다. 6차 기준 범행횟수는 1~6차에서 중복을 제거한 개별 행위 수의 합이다. 현재 직접 피해관계 615쌍 중 14쌍의 값이 확정됐다.

공란에는 원자료 미기재, 구조적 비해당, 판정 보류·미완료, 공개본에서 생략한 자유서술이 포함된다. 공란을 0으로 바꾸지 않는다. 기존 셀 상태와 공개열 대응표를 함께 사용한다. 원문·인용·코더 메모는 로컬 작업본에서 관리한다.
