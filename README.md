# 친밀한 파트너 폭력 판결문 코딩

2026-11-13 승인10기준 재집계 진행 중: 대상366관계 중181관계 적용,185관계 미적용. [현재 적용범위·새 사건대장·쟁점 상태](data/revision_20261113/README.md)를 별도로 제공한다. 새 기준의 전체 재집계와 최종 검증은 아직 완료되지 않았다.

아래 표와 설명은 보존 중인 **2026-11-12 이전 기준 입력본**에 관한 것이다. 판결문 621건의 사건번호, 구조화한 코딩값, 코딩 규칙과 출처별 변수 대응표를 공개한다. 전수 판정과 적용성 검토를 마쳤으며, 판단이 남은 셀은 쟁점 상태표에 별도 표시한다.

[통합 규칙](rules/통합코딩규칙.md) · [통합 코드북](codebook/00_통합코드북.csv) · [공개 열 및 생략 범위](codebook/공개열_대응.csv)

판결문은 문서ID와 법원·대표사건번호로 식별한다. 이전 입력본은 날짜 차수를 사용했다. 승인10기준은 같은 날이라도 독립 사건을 분리하고 연속 사건의 행동은 횟수로 기록하므로, 이전 행 수를 새 기준 사건 수로 해석하지 않는다. 사건차수 전체 3,370행에는 주변인 행이 포함되며, 수단·요구 예비분석은 별도로 선정한 726행이다. 6차 기준 범행횟수는 1~6차에서 중복을 제거한 개별 행위 수의 합이다. 직접 피해관계 615쌍 중 249쌍에 6차 이내 행위 수를 기입했다. 이 중 원문 근사수 포함값은 1쌍이며, 나머지 366쌍은 근거를 남겨 보류했다.

공란에는 원자료 미기재, 구조적 비해당, 판정 보류, 공개본에서 생략한 자유서술이 포함된다. 공란을 0으로 바꾸지 않는다. 기존 셀 상태와 공개열 대응표를 함께 사용한다. 원문·인용·코더 메모는 로컬 작업본에서 관리한다.

## 이번 판정의 범위와 남은 결정

미검토 셀은 0개다. 이는 모든 수치가 확정됐다는 뜻은 아니다. 사건차수 3,370행에는 주변인·공소기각·무죄·기간 기록 등도 포함되므로 그대로 확정 IPV 범행 수로 집계하지 않는다. 기존 승인값과 이번 원문 판정의 상충은 별도 상태표에 남겼다. 날짜·당사자 보완 관찰은 로컬에서 관리하며, 자동으로 신규 범행에 합산하지 않았다.

전체 쟁점 상태표는 미기재·기존 판정불가·분류규칙·상충 등을 포함한다. 공란을 0으로 치환하지 않는다. 분석범위, 원척도 미확정 정의, 보완 날짜의 사건표 편입 및 중복 연결을 확정한 후 목적별 분석표를 추출한다.
