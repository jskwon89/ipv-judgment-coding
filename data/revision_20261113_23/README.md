# 후속23승인 반영 결과

23개 승인 기준을 24관계에 반영했다. 동일 기준 적용인 C020 증거목록 사건 및 ADD297 A-F 날짜별 편취를 포함한다.
보류 유지도 승인에 따른 판정 완료이며 수치 확정과 다르다.
연결 후 364관계, 관찰·사건 1879행. 독립 범행 수와 동일하지 않다.
첫6 정확총수 확정 51관계. 집계범위: {"첫6확정": 242, "포함여부보류·확인분만": 12, "주분석해당없음": 7, "첫6경계보류·확인분만": 103}.

현재 사건·차수·횟수는 재집계_사건대장.csv 및 통합_사건차수.csv를 사용한다. 이전판본_통합_사건차수.csv는 비교용이다.
관계통합의 승인10_ 열은 후속23 기준으로 재집계했으며, 후속23_ 열은 승인 출처·상태를 표시한다. 기존 total_offense_count/n_events_total 및 기간 파생값은 이전 판본 기준이므로 새 사건대장의 분석과 혼합하지 않는다.
보류셀은 무죄·증거목록·진술 단계·날짜/경계·횟수 미상 등 사유를 그대로 제공한다. 아직 입력하지 않은 셀로 간주하지 않는다.
조치 후 25일·49일은 결정일부터 해당 접근/친구신청까지의 기간이다. 첫 재가해 기간이나 고지일부터의 기간으로 쓰지 않는다.
공개본에는 원문·인용·자유서술 근거를 제외하고 코딩값·쟁점코드·승인 규칙을 제공한다.
