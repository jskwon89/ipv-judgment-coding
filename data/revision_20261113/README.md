# 승인10기준 재집계 — 진행 중

10개 기준은 확정되었으며 재적용 대상366관계 중 175관계에 적용했다. 191관계는 미적용이다. 이 파일 묶음은 전수 완료본이 아니다.

- 기존 2026-11-12 통합 자료는 이전 기준 판본으로 보존한다. 날짜별 한 행을 독립 사건 수로 읽지 않는다.
- 새 사건대장은 독립 사건·기간 관찰·불특정 과거력·문서 연결을 구분한다. 모든 행을 사건 수로 합산하지 않는다.
- 명시행위횟수_6차는 확인된 정확횟수의 소계이며, 정확총수와 다르다. 집계범위상태를 함께 사용한다.
- 최소확인범주5는 최소5회 이상이라는 뜻이다. 범위·근사값을 정확값으로 치환하지 않는다.
- 연결된 원심·항소심은 통합관계ID 기준으로 중복 제거한다. 문서는 모두 보존한다.
- 미적용을0 또는 근거 있는 보류로 바꾸지 않았다. 마지막 통합 검증은 아직 수행하지 않았다.
- 공개본에는 코딩값과 쟁점 상태만 담는다. 원문 인용·자유서술 근거·PDF·별지 이미지는 공개하지 않는다.
