# 승인10기준 적용본

대상 366관계 모두 적용했다. 문서 간 연결 후 통합관계 364개, 사건·기간·과거력·공소·연결 관찰 1871행이다. 이 행 수를 독립 범행 수로 합산하지 않는다.

정확한 첫6 행위총수를 산출한 통합관계는 49개다. 나머지는 확인분과 보류셀을 병기한다. 적용 완료는 수량 전부 확정과 다르다.

- 원래 판결문 621건과 모든 관계 783행을 보존한다. 이번 적용은 기존 보류366관계이며, 기존249관계의 판정은 별도 판본으로 유지한다.
- 통합_관계쌍.csv에서 승인10_ 열과 집계범위상태를 사용한다. 적용대상 phd_범행횟수_6차기준은 정확총수만 기입하며, 이전값은 별도열에 남긴다.
- 명시행위횟수_6차는 확인된 부분합이다. 정확총수와 같다고 가정하지 않는다. 최소확인범주5는 최소5회이상이다.
- 새 사건대장의 기록유형이 사건이어도 첫6경계보류 또는 선행차수미상이 있으면 확정차수로 분석하지 않는다. 기간관찰의 집계수는 사건행과 중복합산하지 않는다.
- 날짜와 날짜정밀도를 함께 사용한다. 분쟁 중 날짜·원문 오기·월일 범위는 정확일자로 가장하지 않는다.
- 전체쟁점 목록은 기존 변수쟁점과 이번 쟁점을 합친 이력 포함 목록이다. 이전횟수 쟁점 428행은 대체로 표시했다. 남은 행 전체를 새로운 미검토 셀 수로 해석하지 않는다.
- 공개본은 기존 공개 열 범위의 코딩값·쟁점코드만 포함한다. 원문·인용·자유서술근거·PDF는 로컬에 보존한다.
- _중간.csv는 이전 중간판본이다. 현재 분석에는 이 폴더의 통합_관계쌍.csv, 관계재집계.csv, 사건재구성.csv와 셀별쟁점_상태.csv를 쓴다.
- 로컬 Excel에는 관계통합·판결문·사건재구성·이번셀별쟁점·코드북을 담고, 나머지 단위와 전체쟁점 목록은 ZIP의 CSV로 제공한다.
